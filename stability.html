Stability & Stress Testing Guide

A 1000W system with dual GPUs and a 12-core CPU generates immense heat and transient power loads. Use this guide to ensure your Phase 2 build is rock-solid before committing to long AI training runs or VR sessions.

The "Transient Spike" Test

DANGER: This test pulls maximum wattage. If your PSU is faulty or cables are loose, this is when it will fail.

To verify the **Fortron 1000W ATX 3.1** PSU can handle the simultaneous spikes of two 7800 XTs + the 5900X:

  • Tools (Windows VM): OCCT (Power Test) or Furmark + Prime95.
  • Procedure: Run Furmark on both GPUs while running Prime95 (Small FFTs) on the CPU.
  • Success Criteria: 30 minutes without a shutdown. If the PC turns off instantly, you have a "Power Trip," likely due to using "daisy-chained" PCIe cables. Ensure each GPU has independent cables from the PSU.

Thermal Throttle Verification

With a **3-slot gap**, the top GPU (XFX QICK) will be breathing the hot exhaust of the bottom GPU (Gigabyte Gaming OC).

  • The Test: Run an AI inference loop (e.g., llama.cpp with --n-gpu-layers 100) for 1 hour.
  • Target Temps:
    • Bottom GPU: < 70°C (Fresh air access).
    • Top GPU: < 85°C (Re-circulated air).
  • Mitigation: If the top card hits 90°C+, increase the Lian Li 216 front fan speeds and consider adding two 120mm fans on top of the PSU shroud to "shove" air into the gap.

VFIO Integrity Check

Verify that your Linux isolation is actually working and you aren't losing performance to "interrupt storms."

LSPCI Verification: Run lspci -nnk and ensure both GPUs show Kernel driver in use: vfio-pci.
IOMMU Grouping: Ensure the GPUs are in their own groups. If they share a group with a USB controller or SATA port, you will get "Input Lag."
DPC Latency: Inside the Windows VM, run LatencyMon. If the bars are red, your CPU pinning is likely crossing CCD boundaries.
Network Latency (VR): If using AX200 Hotspot, ensure the channel is set to **5GHz (160MHz)** with minimal interference. Test with a ping to the Gateway inside the headset.

Phase 2 Maintenance

  • BIOS Updates: Check the MSI support page for "Agesa" updates. Newer Agesa versions often improve PCIe 4.0 stability for dual-GPU setups.
  • Dust Management: The Lancool 216 is a high-airflow case, which means it is a vacuum cleaner. Clean the front mesh every 2 weeks or the bottom GPU will start to choke.
