This repository documents the architectural decisions, software evaluation, and performance baselines for a high-efficiency AI workstation delivered in May 2026.

1. The Problem Statement

Design a local inference system capable of running 30B+ parameter models at >10 t/s within a €2,500 budget, optimized for agentic coding workloads (Aider, Cline) while avoiding the "EU Tech Tax."

2. Key Decisions Matrix

Decision Outcome Rationale
Hardware Platform AM4 (Ryzen 9 5900X) Best "bang for buck" for multi-GPU PCIe lanes.
GPU Selection Dual RX 7800 XT (32GB Total) Best price-per-GB of VRAM in the RDNA3 lineup.
Backend Engine llama.cpp (Vulkan) Vulkan out-performed native HIP by 47% in decode tasks.
OS Ubuntu 26.04 LTS Kernel support for latest ROCm 7.1 drivers.

3. Research Findings Overview

  • The 70B Trap: Quantization below 4-bit for 70B models leads to unacceptable latency and cognitive degradation. 32B is the "Goldilocks" zone.
  • Backend Divergence: Native ROCm/HIP is superior for prompt ingestion (prefill), but Vulkan dominates token generation (decode).
  • Agentic Utility: Local inference at ~24 t/s allows for sub-minute refactoring loops in agentic IDEs.
