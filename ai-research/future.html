Turbo Quant & MTP Evaluation

As of May 2026, several "Turbo" optimizations have entered the mainstream. Here is our engineering assessment for the Dual 7800 XT platform.

1. Turbo Quant (IQ quants)

Importance Quantization (IQ) uses RDNA3 matrix cores (WMMA) more efficiently than standard K-Quants.

Status: Tested (Baseline)

Result: Using IQ4_XS provides a ~12% generation boost over Q4_K_M on RDNA3 hardware while maintaining similar perplexity.

2. MTP (Multi-Token Prediction)

Predicts multiple tokens per forward pass. Requires specific model architecture support (e.g., DeepSeek-V3 or Qwen3).

Status: Feasibility Verified

Note: Currently blocked for Qwen 2.5 as it lacks native MTP heads. Highly recommended for future Qwen 3 migrations.

3. FlashAttention (rocWMMA)

A high-speed attention mechanism that reduces VRAM usage and speeds up prefill on RDNA3.

Status: Blocked (Library Bug)

Issue: The librocwmma-dev package on Ubuntu 26.04 is currently missing internal headers (accessors.hpp), preventing source builds. Fallback: Standard HIP attention.

4. Speculative Decoding

Uses a small "draft" model (e.g., Qwen 0.5B) to predict tokens for a larger "target" model.

Status: Recommended

Result: Can double decode speeds for logic-heavy tasks, but accuracy depends on draft/target alignment.

Engineering Recommendation

For current production workloads, prioritize Vulkan for generation speed. Monitor the rocwmma package for fixes; once resolved, native HIP with FlashAttention will likely reclaim the throughput crown.
