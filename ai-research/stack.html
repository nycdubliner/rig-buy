1. Operating System & Drivers

For AMD RDNA3 architectures, high-bandwidth communication requires the latest ROCm stack. We recommend Ubuntu 26.04 for its native kernel support of RX 7000 series features.

# Install ROCm 7.1 stack
sudo apt update
sudo apt install -y rocm-dev rocm-smi
# Verify installation
rocm-smi

2. Inference Engines

Ollama (The Desktop Standard)

Ollama provides the best UX for rapid model testing and shared API access. It handles tensor splitting across both 7800 XT cards automatically.

# Installation
curl -fsSL https://ollama.com/install.sh | sh
# Run current benchmark model
ollama run qwen2.5-coder:32b

llama.cpp (The Performance Choice)

To maximize throughput, manual compilation with HIP (ROCm) or Vulkan backends is required.

# Build for RDNA3 (HIP)
cmake .. -DGGML_HIP=ON -DGPU_TARGETS=gfx1101
# Build for Vulkan (Maximum Decode)
cmake .. -DGGML_VULKAN=ON

3. Integration with Agentic Workflows

Tools like Aider and Cline interact with this stack via the OpenAI-compatible API provided by Ollama (Port 11434).

# Environment override for Aider
export OPENAI_API_BASE=http://localhost:11434/v1
export OPENAI_API_KEY=unused
aider --model openai/qwen2.5-coder:32b
