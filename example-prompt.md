```text
You are helping me build a PC/workstation quote like the Dual AMD Maverick, but treat it as a fresh machine build.

Goals:
- Maximize value for local inference and general compute
- Use a dual-GPU AMD path if it still makes sense
- Prefer a staged buy if that avoids rebuying platform parts
- Focus on real current pricing, not idealized MSRP

Constraints:
- Country: Ireland
- Use live pricing and current availability
- Consider used GPUs if the savings are meaningful and the seller is trustworthy
- Validate motherboard lane layout, slot sharing, PSU sizing, RAM clearance, and GPU physical fit
- Reuse any parts I already own if that is clearly better value
- Avoid buying storage if I already have a usable NVMe
- If a temporary RAM kit is sensible, allow a 32GB bridge kit first and a 64GB target later

What I want from you:
1. Propose the best current build path
2. Split it into buy now / reuse / buy later
3. Give me exact part picks with current prices and sources
4. Call out any compatibility risks or upgrade traps
5. If the dual-GPU AMD path is not the best value, explain the best alternative clearly

Be skeptical. If a part looks overpriced or like a future rebuy, say so.
```
