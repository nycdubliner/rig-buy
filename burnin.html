AI Burn-in & Instrumentation

Verification steps to ensure your Dual RX 7800 XT rig is stable under sustained AI workloads and properly monitored.

1. The "AI Loop" Burn-In

Run a continuous inference loop to stress the VRAM and GPUs with real-world tensor calculations.

# Run this in your terminal to force a continuous long generation
while true; do 
  curl http://localhost:11434/api/generate -d '{
    "model": "qwen2.5-coder:32b",
    "prompt": "Write a 5000 word detailed technical history of the development of the silicon chip starting from the 1940s to the present day.",
    "stream": false
  }'
  sleep 2
done
Run this for at least 2 hours. If the system doesn't reboot and the generation speed (Tokens/Sec) remains consistent, your thermal solution is working.

2. Hardware Stress (gpu-burn)

For absolute mathematical verification of the GPUs, use gpu-burn compiled for ROCm.

git clone https://github.com/ROCm/gpu-burn.git
cd gpu-burn
make
./gpu_burn 3600  # 1 hour stress test
Monitor Power: This will pull the maximum rated wattage (~520W for GPUs alone). Watch for thermal throttling.

3. Live Instrumentation Dashboard

Keep this running in a side terminal while testing to monitor the health of your 7800 XTs.

watch -n 1 "rocm-smi --showpower --showtemp --showuse --showmemuse"

What to Watch For:

  • Junction Temp: Target < 95°C. Throttling starts at 100°C.
  • Power: Each card should hit ~260W under full load.
  • Memory Usage: Ensure both cards are being utilized (Ollama should split the 32B model across both).

4. Log Monitoring

If the system crashes, check the kernel logs for PCIe or driver errors after rebooting:

sudo dmesg | grep -iE "amdgpu|rocm|pcie"
