Evidence policy

  • Benchmark numbers require concrete artifacts in the current workspace.
  • Launch/config claims require concrete command or log artifacts.
  • Capability flags are allowed only when supported by current local artifacts or current repo-local documentation.
  • Missing evidence is shown as pending rather than inferred.
Earlier versions of this page included unsupported figures such as fp8 KV for the verified vLLM run and large context estimates like 376K. Those values remain intentionally absent until backed by present artifacts.
