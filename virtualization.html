Gaming Virtualization Setup (VFIO)

Transform your dual-GPU AI rig into a high-performance gaming workstation. Using KVM/QEMU and VFIO passthrough, you can run Windows at near-native speeds inside Linux.

The Software Stack

  • Host OS: Arch Linux (Rolling release, best Wiki) or Proxmox (Web-GUI managed hypervisor).
  • Hypervisor: KVM (Kernel-based Virtual Machine).
  • Management: libvirt + Virt-Manager (GUI for VM management).
  • Network/VR: **Intel AX200 Passthrough.** Pass the Wi-Fi module to the VM and use the Windows "Mobile Hotspot" feature to create a dedicated 5GHz link for your headset.
  • Performance: Looking Glass (Low-latency frame buffer for windowed VM gaming).
  • Peripherals: evdev passthrough (Keyboard/Mouse sharing via double-Ctrl toggle).
Option A: Two Gamers, One CPU

Maximize hardware usage by running two independent Windows instances simultaneously.

Hardware Allocation:
  • GPU 1: Dedicated to VM 1
  • GPU 2: Dedicated to VM 2
  • CPU (5900X): 5 Cores per VM (Pinned to individual CCDs)
  • RAM: 56GB per VM (Recommended)

Best for: Multi-user households or dual-boxing.

Option B: Single Player (Max Performance)

Dedicate the bulk of the machine to one flagship VR or 4K gaming experience.

Hardware Allocation:
  • GPU 1: Dedicated to VM 1 (Top Slot)
  • GPU 2: Remains available for Host (AI/Encoding)
  • CPU (5900X): 10 Cores (Pinned across both CCDs)
  • RAM: 64GB+ for VM 1

Best for: High-end VR, MSFS 2020, and 4K Ultra gaming.

BIOS & Hardware Checklist

Ensure these settings are toggled in your MSI X570 Unify BIOS:

  • SVM Mode: Enabled (AMD Virtualization).
  • IOMMU: Enabled (Mandatory for hardware passthrough).
  • SR-IOV Support: Enabled.
  • Amd-Vi: Enabled.
  • Primary Video Adapter: Set to the slot you want Linux to use (or use headless).

OS-Level Optimizations

Add these parameters to your GRUB or systemd-boot command line (/etc/default/grub):

amd_iommu=on iommu=pt isolcpus=1-5,7-11 nohz_full=1-5,7-11 rcu_nocbs=1-5,7-11

1. Hugepages (Crucial for VR)

Pre-allocating memory in 1GB chunks prevents the CPU from searching for RAM addresses, eliminating stutters.

# Edit /etc/sysctl.d/90-hugepages.conf
vm.nr_hugepages = 24

2. CPU Isolation & Pinning

The isolcpus parameter tells Linux to ignore these cores at boot, leaving them "pristine" for the VM. In your XML configuration (Virt-Manager), use strict pinning:

<cputune>
  <vcpupin vcpu='0' cpuset='1'/>
  <vcpupin vcpu='1' cpuset='7'/>
  <!-- Continue pinning matching threads to cores -->
</cputune>
The "Gotchas"
  • AMD Reset Bug: The RX 7000 series is more stable, but if a VM fails to restart, you may need the vendor-reset kernel module.
  • Anti-Cheat: Games like Valorant or Call of Duty may detect the VM. You must hide the KVM signature in the XML: 
    <kvm><hidden state='on'/></kvm>
  • Power/Heat: Running two 7800 XTs at full load generates ~500W of GPU heat. Ensure your Lian Li 216 fans are set to a performance curve.
